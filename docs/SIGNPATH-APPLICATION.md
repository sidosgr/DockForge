## Description

DockForge is a free, MIT-licensed Windows desktop utility that lets users create additional taskbars on screen edges or as floating bars. It supports expandable groups, linked folders, application shortcuts and running-window controls across multiple monitors. It is independently implemented in C# and WPF, with self-contained x64 and ARM64 builds packaged into one installer.
