01 / Start here

From setup to your first bar.

DockForge runs alongside the Windows taskbar. Start with one bar, then add more as your workspace takes shape.

  1. Install DockForge.Use the single setup EXE. It selects the x64 or ARM64 application automatically and includes the required desktop runtime. Per-user installation is the default; an all-users installation can require administrator access.
  2. Choose a home.The welcome guide asks for a display and a position. Select an edge, or choose Floating for a free-standing bar.
  3. Choose what it shows.Pick Launcher, Running Apps or Combined. Choose visibility and whether DockForge should start when you sign in.
  4. Add a few essentials.Select installed apps, or start empty and add items from the bar’s New menu. Create your bar when you are ready.
Find Settings anytime. Right-click an empty part of a bar and choose DockForge settings. You can also use the DockForge icon in Windows’ notification area. Launching DockForge again opens the existing instance’s Settings.
02 / Build your bars

A home on every edge.

In Settings → Bars, choose New bar. Select it in the list, give it a name and configure its Placement page.

Placement

Edge or floating

Dock to the left, right, top or bottom of a display. Floating bars can be horizontal or vertical. Each display supports one bar on each edge and multiple floating bars.

Displays

Independent or mirrored

Select one display for an independent bar. Select several to mirror the same bar and its contents. Monitor-only running-app filtering remains local to each copy.

Length

Full, fitted or custom

Full spans the display edge. Fit Contents follows the items. Custom uses your chosen length. Center alignment centers the icons inside long bars as well as positioning shorter bars along the edge.

Modes

Choose its job

Launcher holds your chosen shortcuts. Running Apps shows eligible open windows. Combined keeps your pins and running windows together.

Move, duplicate and lock

Drag the small handle on an unlocked bar to move it. Move toward an available screen edge to dock, or away from the edge to float. Use Duplicate in Settings to start from a copy. Use Lock bar in the bar menu to prevent accidental movement and content changes.

If a display disconnects, its bars stay configured but inactive. Reconnect it or select another display in Placement.

03 / Add & organize

Your essentials, one click away.

Right-click an empty area of a bar and open New. All creation options live in this one submenu.

ChooseUse it for
Installed appDesktop or Store apps available on this PC.
File or shortcutA program, document, .lnk shortcut or other file.
Folder shortcutA folder that opens in File Explorer.
WebsiteAn HTTP or HTTPS address that opens in your default browser.
Group / Linked folderA custom collection, or a live view of a folder’s immediate contents.
Separator / SpacerA visual divider, or adjustable empty space between items.

Drag with a clear destination

Drag an icon along a bar. The accent line marks the insertion point; the first or second half of an item selects the position before or after it. Release to place it. You can also move items between unlocked bars.

The middle of a custom group highlights as a drop target. Dropping an item there adds a copy to the group and keeps the original pin on the bar. Use the group’s outer edges to reorder beside it instead.

Add files by dropping them

Drop files or shortcuts on empty bar space to add pins. Drop files on an app launcher to ask that app to open them; the target application must support opening those files.

Edit the details

Right-click an item and choose Edit item to change its name, target or icon. Program shortcuts can also have launch arguments and a working folder. Removing a shortcut from DockForge does not delete the file it points to.

04 / Groups & folders

Keep a project within reach.

Curated

Custom group

Collect selected apps, documents, folders and websites. Add items in the group editor, drop files into the open group, or drop a bar item into its highlighted center.

Live

Linked folder

Choose a folder and show its immediate contents. The view refreshes when files change. Apply file-type or extension filters to keep the collection focused.

A heading, without the window chrome

Groups open in a clean panel with an in-content heading. Right-click that heading and choose Rename group. Type the name and press Enter to save; press Esc to cancel. F2 also starts renaming while the group has focus.

A name for the view. Renaming a linked-folder group changes its DockForge label. It does not rename the folder on disk.

Icons, labels and shortcut badges

Right-click the heading to toggle Show item labels and Hide shortcut badges. The same options are in the group editor. Without labels, the grid becomes more compact; names remain available as tooltips and accessibility labels.

Badge hiding is enabled by default. For desktop .lnk shortcuts, DockForge uses the shortcut’s custom icon or its resolved target icon without adding the shortcut arrow. Internet shortcuts use a custom icon when provided or a clean website symbol. Unresolved shortcuts use a neutral symbol; choose a custom icon if you prefer.

Choose the right view

  • Grid or list: choose a visual launcher or a readable list.
  • Sort: use name, type, date or manual order. Manual order supports dragging within the group.
  • Filters: linked folders can show everything, shortcuts, or specified extensions such as .exe;.lnk;.url.
  • Open on hover: enable it and set a delay, or keep click-to-open.
  • Keep open after launching: leave the panel available while starting several items. Press Esc when finished.

Resize the panel from its edge. Groups have one level: subfolders open in File Explorer, and groups cannot contain nested groups.

05 / Make it yours

Small details. A better fit.

Open the selected bar’s Appearance and Colors pages. Bar changes are previewed live; Settings itself follows Windows’ light or dark app theme.

1. Set icon sizeThickness resets to the smallest comfortable size for those icons and the current spacing.
2. Add room if you wantIncrease bar thickness afterward. The new icon size becomes your fresh starting point.
3. Tune the finishChoose spacing, alignment, labels, colors, opacity, blur and corner radius.

You can select automatic Windows styling or a Windows 10, Windows 11 or Windows XP style per bar. Windows XP uses the blue Luna palette, Tahoma labels and beveled buttons; its shading rotates for vertical bars. Blur is disabled for that style, and a custom background color still takes priority. Choose a system, light or dark bar theme independently. High contrast follows Windows and takes priority over decorative colors.

Bar labels can show icons only, labels for running windows, or labels for all items. Overflow stays on one row or column; arrows appear when scrolling is needed. Group-label visibility is configured separately for each group.

Built for different window sizes. Settings uses two columns when there is room and one when it is narrower. Some scrolling is expected on small displays or at larger Windows scaling settings.
06 / Running apps

Find the window you need.

Running Apps and Combined bars discover eligible windows on the current virtual desktop. Use Behavior to show only the bar’s monitor or all monitors, combine windows by app, and include or exclude particular apps.

ActionResult
Click a running appSwitch to its most recently used window when switching is enabled.
Click the active appMinimize it when “Click active app to minimize” is enabled.
Shift-clickAsk the app to open another instance, where supported.
Hover an iconInspect its window previews. Leaving the icon dismisses the hover preview immediately.
Right-click an iconChoose a particular window, close a window, open another instance, or pin the app.
Middle-clickClose by default. With several windows, choose the window to close. Change this action per bar to New Instance or None.

Closing asks the application to close normally, so it can prompt you to save. Close All can ask for confirmation. Attention and active-window indicators help identify apps that need you.

Thumbnail versus list presentation is configurable. Minimized-window thumbnail availability depends on Windows’ desktop compositor. Recent Jump List destinations are available where an app identity is known; custom tasks and pinned Jump List entries are not exposed by the API used in this build.

07 / Hide & reveal

There when you need it.

Visibility

Reserve, overlay or hide

Reserve Space asks Windows to keep room for an edge bar. Overlay sits above the workspace. Auto-hide slides the bar away after its configured delay.

Activation

An invisible edge

Move the pointer to the screen edge along the bar’s own span. The activation area has no visible line while Settings is closed. The optional guide helps locate it during setup.

Set reveal and hide delays on the Auto-hide page. The short slide animation follows Windows’ animation preference. A fullscreen application suppresses the bar on that display.

Floating bars

An auto-hidden floating bar can reveal from a small activation tab, a keyboard shortcut, or both. Shortcut-only reveal requires a valid shortcut. Choose a unique combination such as Ctrl + Alt + D.

Hide the Windows taskbar on selected displays

Open Windows & startup. Choose individual displays, Hide on secondary displays, or Hide on all displays. Apply to activate the selection. The secondary-display option keeps the primary Windows taskbar visible.

Restore at any time. Choose Restore Windows taskbars in Settings, the bar menu or the notification-area menu. Normal exit restores taskbars hidden by DockForge; a separate recovery helper is designed to restore them after an unexpected exit.
08 / Save & restore

A setup worth keeping.

Apply & Cancel

Apply saves your changes and keeps Settings open. Save and Close saves and exits. Cancel discards changes since the last Apply, including live appearance edits.

Export & import

Export your setup from Backups & updates to keep a JSON copy. Import validates the file before replacing the setup and creates a backup of the previous saved configuration.

After importing, review your bars and choose Apply to save. Cancel restores the editing session’s previous setup. Exported settings reference files on your PC; they do not bundle apps, documents or custom icon files. Update paths after moving to another computer.

Automatic backups

DockForge retains the newest eight local backup snapshots. Use Restore backup to choose one. Local settings and backups live under %LOCALAPPDATA%\DockForge, with snapshots in its Backups folder.

Startup & updates

Control sign-in startup in Windows & startup. Backups & updates checks the official sidosgr/DockForge GitHub repository automatically. Development previews are included by default; turn this option off to check stable releases only. You decide whether to open the download and run an installer; updates do not install silently.

Diagnostics

Export diagnostics to a local text file when investigating a problem. Review it before sharing: error messages can contain file paths. DockForge does not send usage data or crash reports automatically.

10 / Troubleshooting

Back to a good workspace.

I cannot find an auto-hidden bar.
Move to the exact screen edge within the bar’s configured span and wait for the reveal delay. For a floating bar, use its activation tab or assigned shortcut. Open Settings to check display selection, position and reveal configuration. A fullscreen app can suppress a bar on its display.
The Windows taskbar is hidden and I want it back.
Use Restore Windows Taskbars in DockForge’s notification-area menu or Settings. The installer also creates a Restore Windows Taskbars shortcut. If DockForge is not running, use that shortcut to request recovery.
An item has an exclamation mark or does not open.
The target may have moved, been removed, or live on a disconnected drive. Right-click the item, choose Edit Item and select the current target. DockForge preserves missing pins so you can repair them.
A linked folder is empty.
Check that its target folder exists and is accessible. Review the folder-contents filter and extension list. The group shows immediate contents; it does not recursively expand nested directories. Subfolders open in File Explorer.
I still see a shortcut badge.
Enable Hide Shortcut Badges in that group. Standard desktop shortcuts use their custom or resolved target icon. If a shortcut cannot be resolved, DockForge uses a neutral symbol; choose a custom icon in the item editor or add the installed application directly.
A floating reveal shortcut does not work.
Choose a valid combination with a modifier and avoid shortcuts already used by another application. Duplicate DockForge assignments are rejected; an externally occupied combination is recorded in the local diagnostic log. Keep the activation tab enabled while testing a new shortcut.
I changed icon size and my thicker bar became smaller.
That is intentional: a size change resets thickness to its smallest comfortable value. Increase thickness afterward if you prefer more space. Increasing item spacing may also require more thickness.
There is a graphical flash during reveal.
Use the latest build and repeat the gesture. DockForge 0.1.3 replaced the native clipping animation with a single composited presentation. If a flash remains, note your Windows version, display scaling and graphics driver, and capture the transition for a bug report.
11 / About this build

Built in the open. Designed for your desktop.

DockForge is an independent Windows toolbar application inspired by Linkbar and implemented in a new C# / WPF codebase under the MIT license. It recreates familiar taskbar interactions; appearance can vary between Windows builds.

Development build 0.1.6. Windows 10 22H2 and Windows 11 are the intended targets. The installer contains self-contained x64 and ARM64 applications. Current local verification uses Windows 11 x64; Windows 10, ARM64 hardware and the complete installer lifecycle still need execution testing.

Explorer notification badges and progress reporting are not implemented in this build. Jump List support is limited to publicly available recent destinations. These boundaries matter when comparing DockForge with the Windows taskbar.

This guide contains no remote fonts, libraries or media. It is a single HTML file, works offline, and can be reused with the project’s repository. Updates use the official sidosgr/DockForge repository. Current installers remain unsigned while trusted code-signing approval is pending.
